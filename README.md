# RK3588 Bare Metal

Independent bare-metal OS and bootloader for Rockchip RK3588/RK3588S.

## Development roadmap

- MaskROM and USB download
- SRAM execution
- ARM64 startup
- UART and clock
- DDR initialization
- Exception levels
- MMU and Cache
- GICv3 and Timer
- SMP multicore
- Kernel and Shell
- Peripheral drivers
