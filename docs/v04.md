# v0.4 experimental USB restart and enumeration

Build: make -f boot/v04.mk pack. Reset board into MaskROM, then download using
sudo rkdeveloptool db out/v04/rk3588-baremetal-ram-only.bin (RAM only).
UART 1500000 8N1. First run trb, usb. Run usbstart explicitly to disconnect,
wait 300 ms, reset the DWC3 device core, allocate our own DMA event ring/TRB,
configure control endpoints and reconnect. Inherits board clock and PHY
routing; this is NOT independent cold PHY initialization.
Host: lsusb; sudo lsusb -v -d 1209:0001. Test VID/PID is nonunique and for
private testing only (https://pid.codes/1209/0001/). No Bulk, CDC, download,
storage commands, or flash writes. usbstat displays driver counters.
Run usbstart again for a controlled restart. An interrupted control transaction,
unexpected event or command error can require explicit restart or power cycle.
Do not use rkdeveloptool against the new test device.
Sources: reference/u-boot/drivers/usb/dwc3/{core.h,gadget.h,gadget.c,ep0.c};
Linux DWC3 gadget reset sequence. Not built or tested on target at commit time.
