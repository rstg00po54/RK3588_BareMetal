# v0.5: RK3588S DDR snapshot (read-only)

This is an incremental diagnostic payload, not a replacement DDR blob.
It still packages the vendor v1.18 DDR code and preserves v0.4 USB code.
Build: make -f boot/v05.mk pack. In MaskROM use:
sudo rkdeveloptool db out/v05/rk3588-baremetal-ram-only.bin
Never flash this loader. UART: 1500000 8N1.

Before usbstart: run ddr, then ddr0, ddr1, ddr2, ddr3 individually.
Capture full serial output including vendor DDR startup.
If a command hangs or aborts, report the last printed address; power cycle.
Do not run these lengthy synchronous diagnostics during USB transactions.

The register allowlist uses RK3588 TRM Part2 sec 2.4.1, DDRCTL summary
(https://dl.khadas.com/products/edge2/datasheet/rockchip-rk3588-trm-v1.0-part2.pdf).
PMU1_GRF base: TRM Part1 and reference/linux-6.1/rockchip/rk3588s.dtsi.
OS_REG2..5: https://github.com/torvalds/linux/blob/master/include/soc/rockchip/rk3588_grf.h
DDRCTL, DDRPHY and DDRPHY_CRU bases independently extracted from vendor DDR
v1.18 at file offsets 0xcf38..0xcf94 and matched to TRM Part1.
No DDR writes, no MR read commands, no PHY scan, no clock or PLL changes.
F0 registers are raw bank values, not necessarily the active frequency.
probe32 handles synchronous data abort only, not an interconnect hang.
Do not replay captured registers blindly; status, trigger and training fields
require independent understanding. Not compiled or tested on target at commit.
