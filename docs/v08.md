# v0.8: DDR PHY training-related register snapshot

v0.7 528 MHz board snapshot (CH0..3):
- B0: 2002EF7F on all channels
- B4: 5DFC0202, 5DFC01FE, 5DFC01FE, 5DFC01F9
- B8: 00000210 on all channels
- 580: 00000000 on all channels

DLL_LOCK_VAL = B4 & 0x7ff (original binary instruction at 0x231c).
Values: 514, 510, 510, 505. Do not replay this status field.
The original print function uses additional state and frequency when
converting the DLL count into a time unit.

v0.8 retains the four probes and adds 20 explicit offsets from the
rank-zero read/write training print branches of the vendor v1.18 binary:
- 0x24c4..0x24f0: 0x190+12*i and 0x614+12*i for i=0..7
- 0x2474..0x248c, 0x26e4..0x26ec: 0x18c and 0x610 for special index 8
- 0x2578..0x25ac: 0xdc0 and 0xdc4

These are raw observations; provisional labels do not establish bitfields.
No training triggers, clock changes, writes, or unbounded scans.
Build: bash tools/build-ddr-test.sh freq-only v08
Download from MaskROM using db only:
sudo rkdeveloptool db out/ddr-freq-only-v08/rk3588-baremetal-ram-only.bin
Run ddrphy0, ddrphy1, ddrphy2, ddrphy3 before usbstart.
24 registers per channel. On a hang, save last printed address and reset.
This does not replace the vendor DDR initializer.
Not compiled or tested on the target at commit.
