# v0.7: minimal DDRPHY diagnostic

Four explicit read-only offsets extracted from original DDR v1.18
print_train_result path. 0x230c loads channel descriptor field +8,
0x2310/14/24 load PHY +b8/b4/b0; 0x2454..245c read +580 for rank 0.
No register writes, training start, or blind range reads.
Run ddrphy0..3 before usbstart. If hung, record last address and reset.
Build make -f boot/v07.mk pack for unmodified DDR. For 528 MHz use
bash tools/build-ddr-test.sh freq-only v07 (see updated script).
Use db only, never flash. Not compiled or target tested at commit.
