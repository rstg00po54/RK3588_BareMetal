# OpenBoot v0.2 (experimental)

v0.1 was verified on RK3588S 4 GiB at EL3. It remains unchanged.
Build v0.2 from repository root: `make -f boot/v02.mk pack`.
After a fresh hardware reset into MaskROM: `sudo rkdeveloptool db out/v02/rk3588-baremetal-ram-only.bin`.
Monitor inherited UART2 at 1500000 8N1, no flow control.
Never flash this image. USB commands still time out by design.

Commands: help, cpu, uart, echo, usb. Run usb only after confirming UART RX.
USB diagnostic uses OTG0 0xfc000000 from the reference RK3588S DTS and DWC3
offsets from the reference U-Boot core.h. No USB register writes, event
acknowledgment or DMA buffer reads. The snapshot cannot prove ownership
of the previous USB link. A bus stall or asynchronous abort may still
require a power cycle. An unexpected entry EL or unaligned load address
causes an early exclamation mark and halt. CPU diagnostics report the
inherited MMU/cache state without changing it.

Local Clang/LLD freestanding compile and link checked, no target testing yet.
GNU cross build and packing need verification on the user's host.
